# dsh-autoplay · 刷课连播

一个 DeepSeek Harness 插件：**用带调试端口的 Chrome 挂住课程视频，本节播完自动翻到下一节，并跳过习题。**

Harness **左侧栏**多出一个「刷课连播」图标，点开就是它的面板：填课程视频页地址、点一下按钮就能开始，面板里实时显示播放进度、已连播节数、最近动态，并随时可停。

---

## 它怎么工作

1. 宿主半边在 **DSH 宿主进程内**启动一个带 `--remote-debugging-port` 的独立 Chrome（自己的用户数据目录，与日常 Chrome 互不干扰）。
2. 通过 **CDP（DevTools Protocol）** 读取页面里 `<video>` 的真实进度，而不是猜。
3. 本节播完 → 按**站点规则**找到下一个**视频**并跳过去。
4. 界面半边通过一条本地 HTTP 路由（`/dsh-autoplay`）与宿主通信。

## 站点适配

内置两条规则：

| 站点 | 规则 id |
|---|---|
| 北航雨课堂 `buaa.yuketang.cn` | `buaa-yuketang` |
| 学堂在线研究生院 `graduate.xuetangx.com` | `graduate-xuetangx` |

没匹配到规则时只会用通用兜底策略（文案为「下一节」的按钮、课程链接列表），能不能用取决于那个平台。

规则是**外部的 JSON**，可以自行导入管理，不用改代码：

- 内置：`rules/*.json`
- 你的：`%USERPROFILE%\.dsh\dsh-autoplay\rules\*.json`（**升级不会覆盖**）
- 同 `id` 即覆盖内置那条

**要适配新网站，看 [RULES.md](RULES.md)。** 里面有字段规范、四种翻页手段的优先级、四步适配流程，以及怎么判断规则写对没有。

## 安装

这是本地 bundle，不是 npm 包。克隆后让 DSH 里的 agent 安装指向该目录的 bundle：

```
plugin_manager  action: install_bundle
                target: <克隆下来的目录绝对路径>
```

（该操作需要审批。）安装后建议禁用再启用一次 bundle，以加载最新的 JS 模块代。

**环境要求**：Windows + Chrome 或 Edge；DeepSeek Harness 桌面版。

## 使用

1. 点左侧栏的 **刷课连播** 图标（在「插件」「自动化任务」旁边）
2. 填课程视频页地址，如 `https://…/video/85936697`
3. 点 **启动并监控**
4. **第一次需要在那个人工打开的 Chrome 窗口里登录课程平台**——登录态存在插件自己的配置目录里，和日常 Chrome 不共享

「翻页规则」区可以：查看已加载规则、粘贴 JSON 导入、删除用户规则、**探测当前页面**（拿到真实 DOM 素材，写规则用）、直接查看适配规范。

## 开发

```bash
node selftest.mjs          # 31 项，不依赖浏览器
```

自测覆盖：配置归一化、规则匹配（包含/通配符/跨租户不误伤）、课程前缀判定、翻页表达式可解析、以及界面样式守卫（禁止在品牌色底上写死前景色）。

## 已知限制

- 界面面板的**实际渲染效果未确认**（无法对 Harness 界面本身做浏览器控制）。
- 面板内文字目前只有中文内联，未接入客户端 locale 服务。
- 规则在**启动时**解析；改了规则要停止再启动。
- 浏览器里同时开着多门课时，靠「地址前缀」判断该盯哪一门（曾经会跟错课，已修）。
- 跳过习题依赖课程目录树；没有目录的平台躲不掉习题页，届时会停下并报 `blocked` 而不硬闯。
